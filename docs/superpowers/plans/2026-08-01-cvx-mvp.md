# cvx MVP Implementation Plan (Go backend)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upload your resume once (Claude digitizes it into a structured profile), then for any role — title or full JD — get a tailored one-page ATS-safe PDF in seconds, with gap flags, a what-changed summary, an archive, and optional email delivery.

**Architecture:** Go + Echo backend owns everything: SQLite storage (stdlib `database/sql`), both Claude calls (digitize, tailor), server-side PDF generation (`fpdf`), and email. Next.js is a thin UI that proxies `/api/*` to the Go server. Anti-fabrication guardrail is structural: our code assigns IDs to every profile item/bullet; tailored output must cite those IDs; `ValidateTailored` rejects anything else.

**Tech Stack:** Go 1.22+, `github.com/labstack/echo/v4`, `modernc.org/sqlite` (pure-Go driver, no cgo), `github.com/anthropics/anthropic-sdk-go` (model `claude-opus-5`), `github.com/go-pdf/fpdf`, Resend via `net/http`. Frontend: Next.js 16 + React 19 + TS via Bun.

## Global Constraints

- Layout: `server/` (Go module `cvx`) + `web/` (Next.js). Bun only for web; `go` toolchain for server.
- Model ID exactly `claude-opus-5`. `max_tokens: 16000`, `output_config: {effort: medium, format: json_schema}` on both calls. Never raw-string-parse without schema+validation.
- DB: SQLite file `server/data/cvx.db` (dir gitignored). Raw SQL, no ORM. PDFs stored as BLOBs.
- **Guardrail:** every tailored bullet cites a real `sourceBulletId`, every item a real `sourceId`; IDs assigned by our code, never the model. `ValidateTailored` errors otherwise.
- One ATS-safe single-column PDF template. Filename `Name_Role.pdf`.
- Env (server): `ANTHROPIC_API_KEY` required; `RESEND_API_KEY`, `CVX_EMAIL_TO`, `CVX_EMAIL_FROM` optional; `CVX_ADDR` default `:8080`.
- Tests: `go test ./...` for server; TDD per task. Go SDK note: if a struct/field name in the plan's Claude-call code doesn't compile, fix the name from the compiler error against the installed SDK — do not change the request semantics.
- **Brand/design (binding for Tasks 5, 8, 9):** tailoring identity. Tokens: paper `#EEF0EF`, card `#FFFFFF`, ink `#1C2422`, muted `#5C6660`, edge `#D8DCDA`, chalk (accent) `#2244D9`, gap-weak `#B07818`, gap-missing `#B3341E`. Type: Bricolage Grotesque (display/wordmark), Instrument Sans (body), IBM Plex Mono (filenames, dates, counts) — self-hosted woff2 via `@fontsource`, never a CDN link. Icons: `lucide-react` only — no emoji, no unicode symbols as icons. Signature motif: a short dashed "stitch" line, used in exactly two places (under the wordmark, top edge of the result tag) and nowhere else.
- **Copy rules (binding everywhere text appears, including email HTML and PDF):** sentence case; plain verbs; buttons name the action ("Tailor resume", "Upload resume"); no em dashes or double hyphens in user-facing copy; no exclamation marks; banned words: seamless(ly), effortless(ly), supercharge, unlock, elevate, empower, leverage, delve. Errors state what happened and what to do next. Use the exact strings from the copy deck in Task 9 — do not improvise copy.

```go
func AssignIDs(p *Profile) {
	for i := range p.Items {
		p.Items[i].ID = fmt.Sprintf("item-%d", i)
		for j := range p.Items[i].Bullets {
			p.Items[i].Bullets[j].ID = fmt.Sprintf("item-%d-b-%d", i, j)
		}
	}
}

func ValidateTailored(p Profile, t Tailored) error {
	items := map[string]bool{}
	bullets := map[string]bool{}
	for _, it := range p.Items {
		items[it.ID] = true
		for _, b := range it.Bullets {
			bullets[b.ID] = true
		}
	}
	for _, s := range t.Sections {
		for _, it := range s.Items {
			if !items[it.SourceID] {
				return fmt.Errorf("tailored output references unknown profile item: %s", it.SourceID)
			}
			for _, b := range it.Bullets {
				if !bullets[b.SourceBulletID] {
					return fmt.Errorf("tailored output references unknown profile bullet: %s", b.SourceBulletID)
				}
			}
		}
	}
	return nil
}

var nonAlnum = regexp.MustCompile(`[^a-zA-Z0-9]+`)

func Filename(name, role string) string {
	clean := func(s string) string { return strings.Trim(nonAlnum.ReplaceAllString(s, "_"), "_") }
	return clean(name) + "_" + clean(role) + ".pdf"
}
```

- `schema.go` holds two hand-written JSON-schema `map[string]any` values (`profileSchema`, `tailoredSchema`) mirroring the model structs — every object `"additionalProperties": false` + full `required`; nullable-ish strings just `"type": "string"` (empty string = absent).
- `Digitize`: PDF as base64 document block + extraction prompt ("extract EVERYTHING, invent nothing, empty string for unstated fields, tag bullets with skills") → unmarshal into a no-ID draft struct → build `model.Profile` → `model.AssignIDs`.
- `Tailor`: system prompt (hard rules: select/reorder/rephrase only; cite exact ids; ≤5 items, 2–4 bullets; honest gaps `missing|weak`; whatChanged 2–4 bullets; mirror JD vocabulary only where profile supports it) + user blocks (profile JSON, role input) → unmarshal `model.Tailored` → `model.ValidateTailored` before returning.

Real client (`llm.go`) — fix field names from compiler if the installed SDK differs; keep semantics:

```go
func (a anthropicLLM) GenerateJSON(ctx context.Context, system string, blocks []ContentBlock, schema map[string]any) ([]byte, error) {
	var content []anthropic.ContentBlockParamUnion
	for _, b := range blocks {
		if b.PDF != nil {
			content = append(content, anthropic.NewDocumentBlock(anthropic.Base64PDFSourceParam{
				Data: base64.StdEncoding.EncodeToString(b.PDF)}))
		} else {
			content = append(content, anthropic.NewTextBlock(b.Text))
		}
	}
	params := anthropic.MessageNewParams{
		Model:     "claude-opus-5",
		MaxTokens: 16000,
		Messages:  []anthropic.MessageParam{anthropic.NewUserMessage(content...)},
		OutputConfig: anthropic.OutputConfigParam{
			Effort: anthropic.OutputConfigEffortMedium,
			Format: anthropic.JSONOutputFormatParam{Schema: schema},
		},
	}
	if system != "" {
		params.System = []anthropic.TextBlockParam{{Text: system}}
	}
	resp, err := a.client.Messages.New(ctx, params)
	if err != nil {
		return nil, err
	}
	for _, block := range resp.Content {
		if tb, ok := block.AsAny().(anthropic.TextBlock); ok {
			return []byte(tb.Text), nil
		}
	}
	return nil, fmt.Errorf("no text block in response (stop_reason=%s)", resp.StopReason)
}
```
