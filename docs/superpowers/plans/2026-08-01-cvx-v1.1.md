# cvx v1.1 Implementation Plan — URL paste + cover letter

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement task-by-task.

**Goal:** Two additions to the shipped v1: (1) paste a job posting URL instead of the JD text and cvx fetches it; (2) an optional cover letter generated alongside the resume, as a second PDF.

**Architecture:** Both ride the existing seams. URL paste is a server-side pre-step before `ai.Tailor` (fetch + HTML→text). Cover letter is a second `ai.LLM` call plus a second `pdfgen` document, stored as extra columns on the existing generation row. No new services, no new deps except `golang.org/x/net/html` (HTML parsing; x/ repos are quasi-stdlib).

## Global Constraints

- All v1 constraints hold: copy rules (sentence case, no em dashes, no exclamation marks, banned-words list), stitch discipline (no new decorative elements), 8px grid, tokens, mono for filenames, provider-agnostic LLM via `ai.LLM`, guardrail untouched.
- API stays backward compatible: `/api/generate` without the new field behaves exactly as v1.
- Cover letter must obey the anti-fabrication spirit: prompt constrains it to profile facts; no id-level validation is possible for prose, so the system prompt forbids invented employers/dates/numbers and the letter cites only items present in the profile JSON.
- SQLite migration must be idempotent (ALTER TABLE guarded by a PRAGMA table_info check).
- Copy deck additions (verbatim, the only new user-facing strings):
  - Checkbox label: `Also write a cover letter`
  - Cover letter download: `Download cover letter`
  - URL hint (replaces textarea placeholder): `Paste a role title, a job posting link, or the full job description`
  - Fetch failure headline (reuses generate error headline; detail line carries the server error)

### Task 1: JD fetch — URL paste (server)

**Files:**
- Create: `server/internal/jdfetch/jdfetch.go`, `server/internal/jdfetch/jdfetch_test.go`
- Modify: `server/internal/httpapi/httpapi.go` (pre-step in postGenerate), `web/src/components/Generator.tsx` (placeholder string only)

**Interfaces:**
- `func IsURL(s string) bool` — true when the trimmed input is a single token starting `http://` or `https://` with no whitespace.
- `func FetchText(ctx context.Context, url string) (string, error)` — GET with 15s timeout, `User-Agent: cvx/1.0`, max 2MB body (`io.LimitReader`), non-2xx → error with status; parse HTML with `golang.org/x/net/html`: drop `script`/`style`/`nav`/`footer`/`noscript` subtrees, collect text nodes, collapse whitespace; empty result → error `no readable text at that link`.
- httpapi postGenerate: after the empty-check, `if jdfetch.IsURL(roleInput) { text, err := jdfetch.FetchText(...); on error → 502 {"error": "fetch job posting: " + err}; roleInput = text }`. slog.Error on failure (`jd fetch failed`).

**Steps (TDD):** tests first — IsURL table (URLs yes; titles, multiline JDs, "python http engineer" no); FetchText against httptest.Server (HTML fixture with script/style/nav noise → clean text; 404 → error; >2MB → truncated not error; empty page → error). FAIL → implement → PASS → vet/gofmt → commit `feat: fetch job posting text from pasted url`.

### Task 2: Cover letter — AI + PDF + store (server)

**Files:**
- Create: `server/internal/ai/coverletter.go` (+ schema addition in schema.go), `server/internal/pdfgen/coverletter.go`
- Modify: `server/internal/model/model.go` (CoverLetter type + filename helper), `server/internal/store/store.go` (columns + accessors), `server/internal/httpapi/httpapi.go` (request field, second call, response fields)
- Tests: extend each package's tests

**Interfaces:**
- `model.CoverLetter struct { Greeting string; Paragraphs []string; Closing string }` (json tags: greeting, paragraphs, closing)
- `model.CoverFilename(name, role string) string` → `Name_Role_Cover_Letter.pdf`
- `ai.CoverLetter(ctx, llm LLM, p model.Profile, roleInput string) (model.CoverLetter, error)` — own JSON schema (all levels additionalProperties false + required); system prompt: professional, specific, 3 paragraphs max, references only facts present in the profile JSON, no invented employers/metrics/dates, no em dashes, no exclamation marks, sentence-case prose, no placeholder brackets.
- `pdfgen.RenderCoverLetter(p model.Profile, role string, cl model.CoverLetter) ([]byte, error)` — same fonts/margins as resume; name 19pt SemiBold, contact line, 6mm gap, greeting, body paragraphs 10pt/1.5 line height with 4mm between, closing + name.
- store: idempotent migration adding `cover_pdf BLOB` and `cover_filename TEXT` (nullable) to generations (check `PRAGMA table_info(generations)` before ALTER). `SaveGeneration` gains optional cover args — change signature to `SaveGeneration(t model.Tailored, pdf []byte, filename string, coverPDF []byte, coverFilename string)` (nil/"" = none) and update all callers/tests. `GetGenerationCoverPDF(id) (pdf []byte, filename string, err error)` — (nil,"",nil) when absent. `GenerationMeta` gains `HasCoverLetter bool` json `hasCoverLetter` (true when cover_filename non-empty).
- httpapi: request `{roleInput string, coverLetter bool}`; when true, call `ai.CoverLetter` + `RenderCoverLetter` (cover failure → slog.Error `cover letter failed`, response `coverLetter: false`, resume still succeeds); response adds `coverFilename string` and `coverLetter bool`; new route `GET /api/generations/:id/cover` (application/pdf attachment, 404 when absent); email: attach both PDFs when cover exists.

**Steps (TDD):** per package: failing tests (schema/prompt call shape with fake LLM incl. rejection of missing fields; RenderCoverLetter %PDF + non-trivial + empty-paragraphs safe; store round-trip with and without cover + migration idempotence on an existing v1 DB file; httpapi happy path with coverLetter:true, cover download route, absent → 404, cover-failure-doesn't-fail-generate) → implement → PASS → vet/gofmt → commit `feat: optional cover letter generation`.
